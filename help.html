Help / How to use

Tap a section to open it. Works offline.

1. Install the app

Android (Chrome or Brave): open the app, tap the ⋮ menu, then Add to Home screen or Install app.

iPhone (Safari): tap Share ⬆, then Add to Home Screen.

Open it once while online so it can save itself. After that it works with no signal. The home page shows “Available offline” when it's ready.

2. Scan a data plate

📷 Take photo opens the camera. 🖼 Upload photo picks a picture you already took (JPEG, PNG or iPhone HEIC).

Tips: fill the frame with the plate. Hold the phone square to it, not at an angle. Tilt it a little to get rid of glare.

The 5 steps:

  1. Photo: take or upload the picture.
  2. Crop: the app finds the plate and straightens it. If it asks, drag the 4 corners to the plate edges and tap Use this crop.
  3. Reading: the phone reads the text several ways. Nothing is uploaded.
  4. Check: compare every value with the plate.
  5. Done: the values are on the call card.

Flagged fields are orange with “check”. The app wasn't sure, so look closely. If passes disagreed, tap the right value under “Pick”. Blank means it couldn't read it. It never guesses.

“Looks right”: tick it after you compare model or serial with the plate character by character. Fill call card needs both ticked. Editing a value clears its tick.

Retake: if the read is poor, the app says so and shows Retake first. It opens the camera again. Nothing from the bad read is kept.

3. Fill the call card & troubleshoot

After Check, tap Fill call card. The plate values go into the card. You can still edit them. The card is saved on this phone.

Troubleshoot follows the open call card: it picks the tree for that unit type (mini-split, split AC/HP, compressor or walk-in) and uses its brand and model. Change the card and the tree follows.

Open: work order / customer #, your name (remembered on this phone, even after Clear draft) and the start time, stamped automatically. You can edit it.

Readings: every field shows its unit (psig, °F, A, V). Once the refrigerant, suction psig and °F, and liquid psig and °F are all filled, superheat and subcool appear right there. They use the same PT tables and the same math as the SH / Subcool tool (dew for superheat, bubble for subcool). Only the number is shown. Compare it with the OEM charging chart. Amps show as a % of the plate RLA/FLA (from the plate scan, the Data plate or typed in), with the source. No plate value means no %.

Mid / Close: tap a phrase chip to add it on a new line. The text stays editable. For “Evacuated to ___ microns” the blank is selected, so just type the number. Opening Close stamps the end time. Edit either time and the total updates, past midnight too.

Copy for Service Tech includes the work order, tech, start/end/total time, SH/SC with units and amps %.

4. Manuals & error codes

Manuals and code tables come only from official OEM sources (the maker's own sites and documents), never forums or resellers.

No code table means nobody has typed in that model's error codes yet. Open the manual instead. Its troubleshooting section has them.

5. Send missing model

If there's no manual for your model, tap Send missing model. Only the brand and model number are sent. Photos never leave the phone. Offline? It waits and sends when you're back online.

6. Import gauge report

In SH / Subcool or the call card's Readings step, tap 📄 Import gauge report. Export a report from your gauge app first (CSV, Excel .xlsx, XML or PDF).

Android: you can also tap Share in the gauge app and pick Service Tech (installed app only). iPhone: save the report to Files, then use Choose report file.

  1. File: pick the gauge app, then the file.
  2. Match columns (first time per gauge app): pick which column is suction pressure, discharge pressure, suction line temp, liquid line temp, refrigerant and time, and each unit. It's remembered on this phone.
  3. Check: values shown in psig and °F, converted from kPa/bar/°C if needed. Orange rows need a look. For a data log, ◀ ▶ picks the reading (last one by default). Tap Looks right — fill.

Only numbers you saw on Check are filled; blanks stay blank. Discharge pressure goes into liquid pressure for subcooling (line loss isn't counted). The file never leaves the phone and it works offline. You can always type the readings instead.

7. Tools
    8. Updates

    The version is at the bottom of every page (for example “Version v28”).

    To update: fully close the app (swipe it away from recent apps), then open it again while online. If the version still looks old, close and reopen once more.

    9. Send feedback

    Only your typed text and the app version are sent. No photos, plates or call cards. Offline? It sends when you're back online.
